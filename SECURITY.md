# Security Policy

## Supported Versions

The latest version of this project is currently supported.

## Reporting a Vulnerability

If you discover a security vulnerability, report it privately to the project
maintainer instead of publicly disclosing it.

Please include:

- A description of the vulnerability
- Steps to reproduce it
- Potential security impact
- Any relevant logs or screenshots

## Security Requirements

This project follows Secure Software Development Lifecycle (SSDLC)
principles.

Security requirements include:

- Authentication and authorization must be implemented securely.
- Sensitive credentials must not be hardcoded.
- Dependencies should be regularly scanned for known vulnerabilities.
- Security testing should be performed before release.
- Security checks should run automatically in CI/CD.
